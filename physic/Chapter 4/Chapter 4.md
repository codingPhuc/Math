0. One-line “what this chapter is about” (Layer 1 preview)  
    Newton’s laws as a workflow: define force, relate net force to motion (equilibrium vs acceleration), separate mass from weight via gravity, use action–reaction correctly, and operationalize everything with free-body diagrams.
    

A) Layer 1 — Logic Layer (Big picture + structure)

1. Chapter “map of maps”  
    Keywords/phrases (purpose + flow)
    

- force as vector push/pull; superposition/net force
    
- Newton 1st law; translational equilibrium
    
- Newton 2nd law; ∑F parallel to a
    
- mass vs weight; g field; universal gravitation
    
- Newton 3rd law; action–reaction pairs
    
- free-body diagrams; component equations; solve procedure
    

Simple flow (what leads to what)

- define force → add forces (superposition) → equilibrium criterion (∑F=0) → general dynamics (∑F=ma) → interpret “weight” as gravitational force (and define g) → avoid action–reaction traps → standard solve pipeline via FBD + components.

C) Layer 3 — Important Details Layer (notation + conditions that matter)

5. High-value details index (20 items)
    

6. “net external force” means vector sum of forces on the chosen body/system; don’t mix bodies. Link: Concepts 3, 16, 30. Spine: §4.6 step (1).
    
7. “equilibrium” in this chapter is translational: ∑F=0 ⇒ a=0 ⇒ v constant, possibly nonzero. Link: 5, 25, 34. Spine: §4.2.
    
8. Newton 2 is vector: component equations are the solvable form. Link: 6, 8, 31. Spine: §4.6.
    
9. direction discipline: if ∑F points +x, then a points +x (cannot be opposite). Link: 7, 31. Spine: §4.3.
    
10. mass is scalar “inertia”; weight is a force vector. Link: 9–10. Spine: §4.4.
    
11. weight direction is toward Earth’s center (your sign convention must reflect that). Link: 10, 32. Spine: §4.4.
    
12. g is defined from Earth parameters in this writeup; g is treated as 9.8 m/s² near surface. Link: 12–13, 33. Spine: §4.4.
    
13. universal gravitation uses center-to-center distance r (not surface distance). Link: 11, 24. Spine: §4.4.
    
14. action–reaction forces are equal/opposite but act on different bodies; never cancel inside one FBD. Link: 14–15, 28. Spine: §4.5.
    
15. “mechanical equilibrium” = translational (∑F=0) + rotational (∑τ=0), but torque is deferred. Link: 17, 27. Spine: §4.6.
    
16. when you replace a force by components, don’t double-count the original (draw-only-once rule). Link: 31. Spine: §4.6 method plus vector-component prereqs.
    
17. “constant acceleration” is a condition, not a default; only then use kinematics formulas. Link: 26. Spine: §4.6 step (4).
    
18. units: Newton is the force unit; keep SI consistent across ∑F=ma. Link: 23. Spine: §4.1 + §4.3.
    
19. system choice controls whether tensions/internal forces cancel (whole-system trick). Link: 30, 19–22. Spine: §4.6 step (1).
    
20. “weight” is not “mass”; avoid writing kg as a force. Link: 9–10. Spine: §4.4.
    
21. gravitational field g is a vector in this writeup (points inward), magnitude g is scalar. Link: 12–13, 32. Spine: §4.4.
    
22. ∑F notation implies vector sum; ∑F_x and ∑F_y are separate scalar equations. Link: 8. Spine: §4.6.
    
23. “in equilibrium” can include constant-speed straight motion, not just rest. Link: 34. Spine: §4.6 (i/ii).
    
24. the chapter’s gravitation constants (G, M_E, R_E) appear explicitly; use them as given when needed. Link: 24. Spine: §4.4.
    
25. rotational equilibrium is named but postponed (don’t try to finish rigid-body statics here). Link: 27. Spine: §4.6.
