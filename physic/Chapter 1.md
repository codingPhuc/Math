According to the course handout Chapter_1_Zemansky.pdf, this chapter builds the “measurement language” of physics: SI units, uncertainty/significant figures, and vectors (including components and dot/cross products).

0. One-line “what this chapter is about” (Layer 1 preview)  
    It’s a navigation kit for doing physics numerically and geometrically: measure with SI, report with honest precision, and compute with vectors.
    

A) Layer 1 — Logic Layer (Big picture + structure)

1. Chapter “map of maps”  
    Keywords/phrases (purpose + flow)
    

- SI (metric) system; mks
    
- base vs derived units
    
- unit conversion as algebra
    
- order-of-magnitude estimates

- scalar vs vector quantities
    
- vector addition/subtraction; scaling

- dot product; cross product
    

Flow (what leads to what)

- Choose standard units → convert consistently → estimate scale → report precision honestly → represent directed quantities as vectors → compute with components/unit vectors → use dot/cross products for angles/perpendicular/parallel tests.
