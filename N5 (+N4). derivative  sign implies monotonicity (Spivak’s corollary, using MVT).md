## N5. derivative sign implies monotonicity (Corollary 3 via MVT)

E1. State Corollary 3 precisely:

- if $f'(x)>0$ for all $x\in I$, then $f$ is increasing on $I$
    
- if $f'(x)<0$ for all $x\in I$, then $f$ is decreasing on $I$  
    Include: $I$ is an interval, $f$ differentiable on $I$, and quantifiers.
    

E2. Name the theorem used to prove Corollary 3 (the engine). State its conclusion in symbols.

E3. In the proof, you pick $x_1<x_2$ in $I$. What does the theorem guarantee exists between them?

E4. Replace $f'(x)>0$ by $f'(x)\ge 0$. What changes in the conclusion (strict vs non-strict)?

E5. Replace $f'(x)>0$ by $f'(x)\neq 0$. Is the conclusion still valid? Give either a reason or a counterexample idea.

F1. If $f$ is increasing on an interval, must $f'(x)>0$ at every point                                                                                                                   where $f'$ exists? If not, give a function and the specific point where it fails.

F2. If $f'(x)\ge 0$ for all $x\in I$, must $f$ be increasing (strict) on $I$? Explain.

F3. If $f$ is increasing, what inequality about $f'(x)$ is always true where $f'(x)$ exists? (Choose $\ge 0$ vs $>0$ carefully.)
