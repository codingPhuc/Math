You use **“w.r.t.”** when you need to say **“with respect to [some variable/thing]”**—usually to make clear _which variable or reference_ you’re talking about.

### Main places you’ll use “w.r.t.” in math

1. **Derivatives (most common)**
    
    - “The derivative of (y) **w.r.t.** (x) is (\dfrac{dy}{dx}).”
        
    - “Differentiate (f(x,t)) **w.r.t.** (x), treating (t) as constant.”  
        Use it any time there is more than one variable and you must say _which_ one you’re differentiating with respect to.
        
2. **Integrals and limits**
    
    - “Integrate (f(x)) **w.r.t.** (x): (\displaystyle \int f(x),dx).”
        
    - “Take the limit **w.r.t.** (x) as (x \to 0).”  
        This emphasizes which variable is the integration/limit variable.
        
3. **Describing how one quantity changes when another changes**
    
    - “Area of the circle increases **w.r.t.** radius (r).”
        
    - “Position changes **w.r.t.** time (t).”  
        Here it means “as the other variable changes.”
        
4. **When _not_ to use it**
    
    - In formal English essays (MLA, etc.) write out “with respect to” or rephrase.
        
    - Don’t use it when there’s only one obvious variable; just saying “differentiate (f(x))” is enough.
        

So in your solution notes you might write:

> “Differentiate both sides **w.r.t.** (x).”  
> “Now integrate the expression **w.r.t.** (u).”

That’s exactly the right kind of usage.

---

### Definitions

- w.r.t.: Abbreviation for “with respect to,” indicating which variable or reference you are focusing on.
    
- derivative of (y) w.r.t. (x): The rate at which (y) changes when (x) changes, written (\dfrac{dy}{dx}).
    
- integrate w.r.t. (x): Compute (\displaystyle \int f(x),dx), treating (x) as the variable of integration.
