### How to use in prompts

- “Use **WRIT-STYLE-WILLIAMS** ideas to tighten these sentences.”
    
- “Check my MLA citations against **WRIT-MLA-HANDBOOK**.”
    
- “Explain this theorem from **MATH-LOGIC-ENDERTON** in simple terms.”
    
- “Help me revise **ESSAY-ENTR-BARRIERS** for clarity and structure.”
    

If you add new files later, keep the same pattern:  
**[SUBJECT]** = WRIT / MATH / ENG / STUDY / ESSAY,  
**[TYPE]** = STYLE / ARG / LOGIC / SYLLABUS / NARR,  
**[KEYWORD]** = 1–2 words you recognize instantly.

---

**Definitions**

- **ID:** A short code you paste into prompts so we both know which resource you mean.
    
- **Subject tag (e.g., WRIT, MATH):** The broad domain of the resource (writing, math, etc.).
    
- **Type tag (e.g., STYLE, SYLLABUS):** The kind of resource (style guide, syllabus, narrative, etc.).
