Source policy (project-only, cite everything important)

- Use only the materials in my project folder that are available to you in this chat (uploaded PDFs/docs/notes). Do not use the web.
    
- You must cite sources throughout, with page numbers.
    
- Treat “project folder” as: every file I have uploaded/provided in the conversation. Use all relevant files, not just one.

- Inline citation format: (FileName p.#) or (FileName pp.#–#). Multiple: (FileA p.#; FileB p.#).
    
- Page numbers must be the PDF page number (1 = first page in the PDF viewer), unless the source clearly has printed page numbers; if it does, include both like: (FileName PDF p.12; printed p.67).
    
- End with Works Cited (MLA-like) using only the project files actually cited.

Exposition style

- Book-chapter prose with clear section headings. No chatty filler. No bullet-dump chapters.
    
- Define every term before using it. State notation, coordinate conventions, sign conventions, and units.
    
- Derive key formulas step-by-step, and state assumptions at each step.
    
- Mostly conceptual explanations. Examples are allowed only to clarify understanding (not number-heavy grinding).
    
- For each major idea, include at least one “misconception + why wrong + fix” segment.

8. Answers to checkpoints
